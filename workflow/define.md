# Define the comparison

Read the assigned note, [scientific scope](../AGENTS.md) and the skill's
[Explorer procedure](../.agents/skills/experiment-loop/references/explorer.md).
Record the question, primary metric, matched controls and decision rule in one
pilot note or the campaign experiment note.

Declare the network and analog subset, teacher, data/cohorts, hardware regime,
fault/write/drift semantics, random coupling, adaptation methods, selection and
physical cost measures. Keep unresolved scientific choices explicit. Set time,
compute and storage limits before preparing a launch.

Use [the architecture map](../docs/architecture.md) to locate an existing capability.
Configuration changes do not require a new runtime. When an implementation is
missing, identify its responsible boundary before extending it.
