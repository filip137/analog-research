# Result: exp-010 — CIFAR migration and reproducibility audit

## Evidence and coverage

Completed locally on 2026-10-04 under the user's migration request. The
[versioned receipt](../../../migration-receipt.json) pins source commits, archive
hashes and validation outputs. Detailed files are in
[the audit directory](../../../../../results/cifar-migration-20261004/).
Both original worktrees and the LoRA worktree were left unchanged.

The ResNet source was captured including its dirty files at commit
`e3052ac1f469fa14187a8c72d773f3e940010505`; the dense source was clean at
`db93217c69444f93761be6eadab0eae15ccbad1d`. Full source snapshots preserve
4,994 and 1,092 files respectively, excluding private human notes. Per-study
source snapshots and original runtime manifests are also retained.

All 70,281 donor artifact files passed source/destination SHA-256 checks:
69,968 from ResNet and 313 from dense CIFAR. Existing source hardlinks were
preserved within the copy, using independent filesystem reflinks. The external
CIFAR-10 dataset symlink was replaced in the destination by a separately verified
local copy. The two missing-as-files sweep source receipts were recovered with
their exact hashes from the retained source-v1/v2 archives.

All 755 native attempts have locally resolvable, hashed config/input bindings:
753 complete and two failed. Attempts include canaries, superseded revisions and
implementation stages; this count is not scientific replicate coverage. The nine
historical experiment records separately retain final-study control counts.

## Reproduction and numerical checks

- All 755 saved resolved configs parse with the integrated public experiment
  registry; all required input hashes resolve within HWA. The helper prints
  commands and never silently launches training.
- Six report families were rebuilt into new audit directories: dense, full-five-
  epoch, fault sweep, OM open-loop, OM closed-loop LR and five-stage comparison
  tables. All 29 comparable CSV tables match, including all 172,644 row values.
- The final CIFAR/CLI regression group passed **170 tests**. The relocation and
  staged-dependency followup passed **37 tests**. Shared crossbar/HWA/workflow
  tests are preserved in the initial and followup logs (overlapping groups,
  not additive totals). Seven initial failures were fixed: two tests required
  CUDA unnecessarily, one merged test lacked `SimpleNamespace`, and four
  dependency tests needed the original study/reference fixtures. Their affected
  groups passed after repair. Two optional checks were skipped in the initial run.
- Independent AIHWKit 1.1.0 checks pass for repeated OM/PCM populations, native
  PCM SET/RESET, endpoint noise and drift compensation. Endpoint-noise maximum
  absolute error versus the native reference is zero in that check.
- Both pinned ResNet-32 checkpoints load strictly. On 16 actual test images per
  dataset, four/eight-convolution ideal crossbar mappings preserve all predicted
  classes; maximum logit error is below 1e-5. This bounded mapping smoke is not a
  rerun of the full test-accuracy benchmark.

No full HWA, pretraining or recovery training was launched. Historical numerical
training equivalence across different GPU/PyTorch environments is not asserted.

## Retention and receipt reconciliation

Native result manifests list **21,885 retained artifacts**, all matching their
recorded SHA-256 and size, and **46,400 absent intermediate checkpoint paths**.
Every absent artifact is in the September 25 deletion inventory; there are no
unexplained missing files or retained-artifact digest mismatches.

Strict metadata inspection validates 121 complete-or-failed bundles as stored.
112 runs reference intentionally removed epoch 1–4 states, and 618 have an
original prepared-study digest that differs from the collected `study.json`.
These groups overlap. Source/destination matching proves these omissions and
receipt discrepancies predate migration. They remain recorded rather than
rewriting immutable manifests or calling all historical bundles fully valid.
Final/selected/P0 states and numeric curves remain; deleted intermediate states
require retraining if needed. The original
[retention record](../../../../../results/cifar-migration-20261004/CHECKPOINT_RETENTION_20260925.md)
and all exception lists are preserved.

## Decision and limits

The migration contract is satisfied: the HWA tree contains the retained evidence,
source snapshots, active reproduction code, configs, data and reporting tools.
The [guide](../../../../../docs/cifar_reproduction.md) supplies local replay/report
commands. Large artifacts remain ignored and must accompany a checkout on a
new machine. The campaign imports remain `imported-summary` with empty verdicts;
this engineering audit neither finishes their scientific reviews nor establishes
a general need for on-chip learning. No DRN/EP pruning was performed in this migration.
