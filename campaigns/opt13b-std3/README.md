# OPT-1.3B pretrained ratio3 DRN sources

See [study #68](https://github.com/filip137/on-chip-learning/issues/68) for scope and GPU accounting. Use a native worktree and interpreter, the pinned OPT-1.3B checkpoint as both teacher and logical source, and the same generated corpus as the paired crossbar source. L12 selects decoder layers 12–23. L24 selects layers 0–23. Keep the perfect-diode solver T=4, K=4, A=5, B=0.1 and digital attention. The native fit calibrates readout on the first shared training window. Prepare first measures the original mapped-model KL, then applies ratio3 once, scaling the bias current and clipping channel peaks. The artifact stores mapped conductance masters and scaled bias currents. HWA samples around these masters, in the historical std3 coordinate (0.03 × 39.6 µS). Training constrains physical targets to the ratio3 window [27, 88.2] µS. Reload and deployment use the stored coordinates. Deployment records the programmed RMS error per matrix in µS.

Use 1e-4 analog/calibration and 3e-6 digital peak rates multiplied by the screen factor. Use the established recipe B Adam hyperparameters and clip norm 1, with the same token order, update budget, warmup fraction and cosine schedule as XB. The paired screen factors are 0.1, 1 and 3. Select by mean programmed development KL on assignments 211001/211002 with equal healthy and random-3% weight. Keep step zero eligible. The study specifies the single edge extension and comparison against initialization.

Render a native config and plan using the corpus digest emitted by XB. For canaries set DEPLOY to canary. For production use held-out. Omit --source-deployments from screen plans. Pass the pinned teacher for both source arguments. Set absolute SRC, PY, TEACHER, SPEC and PLAN paths in the executing environment. Each case has a distinct output directory.

```bash
"$PY" -m campaigns.opt13b-std3.configure --depth "$DEPTH" --phase "$PHASE" --factor "$FACTOR" --stage hwa --corpus-sha256 "$DIGEST" --output "$SPEC"
"$PY" -m ebl lifecycle plan "$SPEC" --teacher-weights "$TEACHER" --source "$TEACHER" --worktree "$SRC" --python "$PY" --output "$PLAN" --source-deployments "$DEPLOY"
"$PY" -m ebl campaign run --manifest "$PLAN/campaign.json" --output-dir "$RUNS" --dry-run
```
