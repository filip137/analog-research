# Measured-cohort adaptation

What survives reassignment to held-out measured devices, and which updates recover performance at a useful write cost?

Common-window transfer can lose most initial accuracy yet recover after measured-state adaptation. Global-nearest access is a strong programming assumption, not sequential pulse evidence. The corrected cohort-B passive LoRA run stays nearly flat; deadbands and probabilistic writing mainly reduce requests. Four-device sign and threshold controls have different initialization substrates and cannot be pooled indiscriminately.
