# Pilot: port OPT-1.3b and measure HWA cost for L12 and L24

State: probe launched 2026-11-19. Branch: `exp/20261118-opt1p3b-port`.
Coordination: [on-chip-learning#68](https://github.com/filip137/on-chip-learning/issues/68).
Authorization (user, 2026-11-18): port OPT-1.3b with analog subsets of half
(L12) and all MLPs (L24), for general-purpose HWA sources. HWA training may run
on Jean Zay A100s if it is too slow elsewhere, and the cost probe may run there
too. No HWA training budget is approved yet; the user sets it after the probe.

## Question and decision
1. Does the existing `opt_mlp_suffix` pipeline run OPT-1.3b unchanged? OPT-1.3b
   has the same pre-LN layout as OPT-125M; only the shape changes.
2. What are the throughput, peak memory and bundle sizes of whole-model HWA at
   L12 and L24 on one A100 80 GB (Jean Zay `gpu_p5`)?

Decision: the probe numbers set the HWA token budget and GPU-hour request,
and decide whether memory engineering (micro-batches, activation
checkpointing, bf16) or MLP-only HWA scope is needed. MLP-only scope is a
scientific choice for the user.

- Measurements: wall time and peak memory per stage, HWA tokens/s, selection

  probe result (it decides the memory-engineering step).
